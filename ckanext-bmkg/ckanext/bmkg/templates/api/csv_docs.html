Mengembalikan daftar seluruh dataset CSV terbuka yang terdaftar di Portal Open Data BMKG beserta metadata spesifik, pilar, dan URL endpoint masing-masing.

GET /api/csv/{dataset_slug}

Mengambil baris observasi data CSV dalam bentuk JSON berstruktur lengkap dengan informasi pagination, total record, dan metadata filter.

Parameter Query:

Parameter Tipe Default Deskripsi
limit integer 100 Jumlah baris data yang dikembalikan (maksimal 10.000 baris per panggilan). Set 0 untuk semua.
offset integer 0 Indeks data awal untuk mendukung paginasi data berskala besar.
q string - Pencarian teks bebas yang dicocokkan ke semua kolom data.
sort string - Pengurutan data berdasarkan nama kolom, contoh: tanggal desc atau suhu_max asc.
<nama_kolom> string - Penyaringan langsung pada nilai kolom spesifik, contoh: ?provinsi=Jawa+Barat atau ?stasiun_id=96749.

GET /api/csv/{dataset_slug}.csv & /api/csv/{dataset_slug}/schema

Stream CSV: Mengalirkan berkas CSV murni standar RFC 4180 (sangat ramah untuk pembacaan langsung di Python Pandas, R read.csv, dan Excel). Tambahkan ?download=1 untuk memicu unduhan file.
Skema Kolom: Menghasilkan tipe data terinferensi (numeric/text), ringkasan statistik (min, max, mean), jumlah nilai non-null, dan sampel data.

GET /api/csv/remote  •  POST /api/csv/convert

Fitur konversi mandiri publik. Konversikan berkas CSV apa pun (melalui URL publik atau payload upload) menjadi REST API endpoint terstruktur seketika dengan filter, sorting, dan kalkulasi skema otomatis.

Cuplikan Kode Pemanggilan API (Siap Pakai)

Gunakan cuplikan kode di bawah ini untuk mengintegrasikan data BMKG secara langsung ke dalam sistem atau aplikasi Anda:

cURL Terminal Command 
# Ambil 10 baris observasi cuaca dalam format JSON
curl -X GET "http://localhost:5000/api/csv/cuaca-harian-cengkareng?limit=10"

# Unduh langsung berkas stream CSV
curl -X GET "http://localhost:5000/api/csv/cuaca-harian-cengkareng.csv" -o cuaca_cengkareng.csv
