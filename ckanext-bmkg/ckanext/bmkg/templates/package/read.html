             Parameter Query yang Didukung:
          

          
    
            
  • ?limit=100 : Batasi jumlah baris data yang diambil (default: 100, maksimal: 10000).
    • 
            
  • ?offset=0 : Indeks baris awal untuk paginasi data.
    • 
            
  • ?q=kata_kunci : Pencarian teks bebas di seluruh kolom tabel.
    • 
            
  • ?sort=nama_kolom [asc|desc] : Pengurutan data (contoh: ?sort=tanggal desc).
    • 
            
  • ?<nama_kolom>=nilai : Filter spesifik nilai kolom (contoh: ?provinsi=Jawa+Barat).
    • 
            
  • ?format=csv : Mengembalikan output murni teks CSV alih-alih JSON.
    • 
          

        


        
        

          Contoh Script Pemanggilan API (Siap Pakai):
        


        

          

             1. Python (Pandas - Analisis Data Langsung):
            
          

          
import pandas as pd

# Baca data CSV langsung ke DataFrame melalui endpoint BMKG
url = "{{ request.host_url.rstrip('/') }}/api/csv/{{ pkg.name }}.csv"
df = pd.read_csv(url)

print("Dimensi dataset:", df.shape)
print(df.head())

        


        

          

             2. Python (Requests - Format JSON):
            
          

          
import requests

url = "{{ request.host_url.rstrip('/') }}/api/csv/{{ pkg.name }}"
params = {"limit": 20}
response = requests.get(url, params=params)
data = response.json()

if data.get("success"):
    meta = data["meta"]
    records = data["data"]
    print(f"Total baris tersedia: {meta['total_records']}")
    print(f"Baris diambil: {len(records)}")
    for r in records[:3]:
        print(r)

        


        

          

             3. JavaScript (Modern Fetch API / Node.js):
            
          

          
fetch("{{ request.host_url.rstrip('/') }}/api/csv/{{ pkg.name }}?limit=10")
  .then(res => res.json())
  .then(json => {
    console.log("Status API:", json.success);
    console.log("Total Data:", json.meta.total_records);
    console.table(json.data);
  })
  .catch(err => console.error("Gagal mengambil data:", err));

        


        

          

             4. cURL (Terminal / Command Line):
