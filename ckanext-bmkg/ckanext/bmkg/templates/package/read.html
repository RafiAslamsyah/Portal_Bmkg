Akses DataStore & Action API Pengembang

Aplikasi pihak ketiga, sistem cerdas, dan peneliti dapat mengambil data secara terprogram menggunakan protokol HTTP REST API standar CKAN 2.10+.

{{ api_url }}

Contoh Script Pemanggilan API:

1. cURL (Terminal / Command Line): 
curl -X GET "http://localhost:5000{{ api_url }}"
2. Python (Requests Library): 
import requests

url = "http://localhost:5000{{ api_url }}"
response = requests.get(url)
data = response.json()

if data.get("success"):
    records = data["result"].get("records", [])
    print(f"Berhasil mengambil {len(records)} baris data BMKG.")
    for r in records[:5]:
        print(r)
3. JavaScript (Fetch API / Node.js): 
fetch("http://localhost:5000{{ api_url }}")
  .then(response => response.json())
  .then(data => {
    console.log("Status API BMKG:", data.success);
    console.log("Records:", data.result);
  })
  .catch(error => console.error("Error fetching data:", error));
